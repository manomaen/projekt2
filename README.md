# projekt2

Übungswebsite mit Mode- und Shop-Layout aus meiner Lernphase mit HTML5 und CSS3. Der Schwerpunkt lag auf Seitenaufbau und Gestaltung.

## Technologien
- HTML5
- CSS3

## Lokal ansehen
Repository herunterladen, entpacken und index.html im Browser öffnen. Für extern eingebundene Schriftarten und Symbole ist eine Internetverbindung nötig.

## Einordnung
Dies ist ein Lernprojekt, kein produktiver Onlineshop.
